# Track: Switch LiveData to Flows

This track migrates the codebase from using Android `LiveData` to Kotlin `Flows` (specifically `StateFlow` and `SharedFlow`) for reactive state management. This improves compatibility with Kotlin Coroutines and simplifies testing.
